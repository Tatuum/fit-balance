# 0008. Original app spec (raw)

Date: 2026-09-15
Status: Superseded by 0009 (turned into a concrete plan)

User enters measurements of the body
App draws a silhouette based on these measurements
App calculates balance points and shows them as "balansed" or "imbalansed"
app proposes some common silhouettes to recreate (user can choose one) and app draws dotted lines above the user's silhouette to show corrected silhouette and propose outfit combos to recreate it. (and show them as a simple drawing)
